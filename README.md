# Healthcare Chatbot / Symptom Diagnosis System

A Python-based healthcare application that analyzes user-reported symptoms and provides diagnostic predictions using machine learning. Includes both a Tkinter GUI and a command-line version.

## Features
- Symptom-based disease prediction using trained ML model
- Tkinter GUI for interactive symptom input
- Console version for command-line usage
- Doctor recommendation based on diagnosis
- Training and testing datasets included

## Project Files
| File | Purpose |
|------|---------|
| QuestionDiagnosisTkinter.py | Tkinter GUI app for symptom diagnosis |
| healthcare_chatbotConsole.py | Console-based chatbot |
| Training.csv | Model training dataset |
| Testing.csv | Model testing dataset |
| doctors_dataset.csv | Doctor recommendation data |

## Tech Stack
- **Language:** Python
- **GUI:** Tkinter
- **Libraries:** pandas, scikit-learn, numpy
- **Data:** CSV-based symptom-disease mapping

## How to Run
1. Install dependencies:
   pip install pandas scikit-learn numpy

2. Run the GUI version:
   python QuestionDiagnosisTkinter.py

   Or the console version:
   python healthcare_chatbotConsole.py
